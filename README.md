
Mjolnir Mod
___________

Use Mjolnir in Minecraft to kill mobs and enemies. This weapon can strike lightning and deal heavy damage.

How to use:

Press Q to drop Mjolnir and send it flying in a given direction. On impact with the ground and mobs it will return to you. If the hammer hits a mob, it will strike lightning at their block position.
Right mouse click the ground to spawn lightning.
